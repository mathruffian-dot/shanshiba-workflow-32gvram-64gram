# 04 自審清單

原則：**交給人看之前，agent 自己先審完、修完**。人只負責主觀判斷（嘴型細節、語氣、好不好笑）。

## review.py 五遍

```
H3 venv:    python review.py cut/<片名>_vN_1080p.mp4          # 第 1、3、4、5 遍
Voice venv: python review.py cut/<片名>_vN_1080p.mp4 --asr    # 第 2 遍
```

| 遍 | 檢查 | 怎麼判斷 |
|---|---|---|
| 1 | 逐鏡抽 4 格拼成總覽圖 | **一定要逐張人工看**：鏡頭漂移、多出人、臉換人、多手多腳、手沒動、背景亂動、老師碰學生、學生面向 |
| 2 | 每句台詞在成片裡 ASR 一次 | 比對分數 <1 的逐句聽；同音同調的辨識字錯不算 |
| 3 | 色度雜訊 | >0.54 **且**比首幀高 25% 以上才警告（畫面本身細節多不算） |
| 4 | 黑畫面、定格（>0.8 秒不動）、響度、峰值 | −15.5 LUFS 左右、峰值 < −1.5 dBFS |
| 5 | 切點前後對照圖、接點明暗差、台詞重疊、台詞被鏡尾切掉 | 明暗差 >12 警告 |

## 常退件清單（人最常抓到的問題）

逐條確認，**不要讓看片的人來抓**：

- [ ] 多腿、多手（踢腿高峰格要看原解析度）
- [ ] 手該動卻沒動
- [ ] 背景的人亂動、突然出現或消失
- [ ] 臉糊、臉換人
- [ ] 接點明暗跳、動作不連貫、硬切
- [ ] 台詞重疊
- [ ] 念錯字、聲調怪、腔調不是台灣腔
- [ ] 道具亂飛（球飛走、紙消失）
- [ ] 多出人（尤其多一個老師）
- [ ] 頭套變老虎、頭套眨眼
- [ ] 黑板或紙上出現亂碼字
- [ ] 上課鏡背景沒有同學
- [ ] 學生沒有面向黑板、窗戶換邊

## 原則

- **不合格就重拍到合格**，不靠剪掉或插別的鏡頭躲。一批 6 個 seed 常常只有 1 個全過。
- 每支片至少看一張 100% 原尺寸全幀；只看縮圖會漏判雜訊和第三條腿。
- 接點明暗要量成片，不量原始鏡頭（後製會改亮度）。
- 給人看**並排影片**，數字只當備註。人是用眼睛判斷的。
- 技術 QA 通過 ≠ 使用者驗收通過，兩者分開記錄。沒量的東西（例如逐音素對嘴）照實寫「沒量」。
- 回報時用**成片時間碼**對應鏡頭；沒被點名的鏡頭不要動。

## 審片工具（2026-11-06 收錄）

- `tools/framecheck.py <成片>`：每秒一格總表（每格 480 寬，看得出背景的人）。**每支片交出去前一張一張看**：背景冒人、糊掉、道具不連戲、牆上冒旗子。
- `tools/clipcheck.py <資料夾>`：逐鏡算跟首幀的相關係數，< 0.7 標 CHECK＝H3 自己切鏡或構圖漂走。
- `tools/flashcheck.py --clips <資料夾>`：抓整個畫面閃一下（Veda 造成）；成片模式 `flashcheck.py <成片> --tl timeline.json` 列出閃的影格與所在鏡。
- `tools/stutter.py check <各鏡 clip.mp4>`（2026-11-17 起每支片交片前跑）：H3 有時每 4 格停一格，看起來像畫面在震。標 STUTTER 的用 `stutter.py fix in.mp4 out.mp4`（光流補格，聲音不動）修；標 SHAKE（人走動時一格前一格後來回抖）的 fix 修不掉，要換 seed 或改 14 步。兩種都要 0 支。
- `tools/blurcheck.py --clips <資料夾>`（2026-11-18）：動作糊邊。比「正在動的區域」和「沒在動的區域」的銳利度，p10 < 0.90 判 BLUR，要重拍（原因是動作又快又大，不是步數）。抓不到半透明殘影，群眾伸手、揮手的鏡頭要放大逐格人看。
- `tools/split_frame_check.py <首幀資料夾>`（2026-11-18）：首幀被畫成上下或左右兩格的拼圖（提示詞寫了兩個時間點的動作時會發生），H3 會照著拍成分割畫面。要 0 張；修法是首幀只寫動作開始前的一個姿勢。

- `tools/preflight.cmd check <成片.mp4>`（2026-11-24）：成片層的檢查總表——規格（1920x1080／1088x1904、24 fps、有聲音軌）、響度（−16 LUFS ± 1、真峰值）、頓挫篩檢（逐秒窗掃整支成片、列出可疑時間碼）、整片實播。「要人看」的項目要用 `preflight.cmd sign` 簽核才算完成；成片重出或工具改版後舊簽核自動失效。**回傳 0 只是成片層的輔助依據**，上面逐鏡的檢查照跑。`preflight.cmd selftest` 用合成片驗證判定邏輯。
- `tools/codex_review.cmd --ask ask.md --attach …`（2026-11-24）：把計畫、程式、劇本、成片資料送給 Codex CLI 審（唯讀、材料從 stdin 餵）。做法見 `agent/skills/codex-review/`。
