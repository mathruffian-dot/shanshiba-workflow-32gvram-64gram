# 01 總覽與架構

## 目標

- 每月 5–10 支、每支 1–3 分鐘的原創短片，主角是戴美洲獅頭套的老師「山獅霸」和三個學生（阿福、阿禾、班長小雯）。
- 16:9 橫式、24fps、YouTube 為主。之後要做 Shorts 不裁切成品，而是用 9:16 重新生成。
- 核心是**可重複的製作管線**：換劇本、換角色，同一套流程照樣跑。

## 三層架構

```
┌─ 知識層：讓人和 AI agent 都知道「怎麼做、為什麼」─────────────┐
│ CLAUDE.md / AGENTS.md：agent 入口（最新決策寫在最上面）          │
│ 專案現況、資源索引：研究、實測、「答案索引」（已驗證的做法）     │
│ 記憶：一事一檔的使用者偏好、退件理由、專案事實                   │
│ 技能：編劇（shanshiba-drama）、Blender 預演（blender-previs）    │
│ 角色資產卡：定妝照、轉面圖、表情表、鎖定提示詞、聲音             │
└─────────────────────────────────────────────────────────────────┘
┌─ 全域工具層 C:\AI\tools：所有片、所有 agent 共用 ─────────────┐
│ h3_shot.py、img25.py、gen_voice.py、breeze_batch.py、stt.py、   │
│ pron_check.py、pron_compare.py、gen_music3.py、upscale_vsr.py、 │
│ noise_scan.py、start_comfy                                      │
└─────────────────────────────────────────────────────────────────┘
┌─ 每片腳本層：每支片一個資料夾，複製範本後只改表格 ─────────────┐
│ gen_frames → voice_stage1 → voice_pick → plan_h3 → pipeline_gen │
│ → post_fx → music_scenes → assemble → render_ending → review    │
│ run_queue.sh 串起來，等 GPU 空出來就自動跑（可以過夜）          │
└─────────────────────────────────────────────────────────────────┘
```

### 為什麼這樣分

- **工具層穩定、每片層可拋**：工具改一次全部受益；每片腳本是「表格＋少量專屬特效」，複製上一支改表格最快，不追求抽象化。
- **知識層是重點**：AI agent 每次對話都是新的。把「使用者退件過什麼、為什麼」寫成檔案，下一個 agent 才不會重犯。這個專案超過一半的品質提升來自這一層，不是換模型。

## 工具選擇

| 環節 | 用什麼 | 為什麼不用別的 |
|---|---|---|
| 首幀 | OpenAI Image 2.5（雲端，medium 畫質） | 本機 Qwen-Image 2.1 2K／50 步畫質沒差，但光線氛圍偏白日光、雙人鏡角色不太像 |
| 影片＋音效 | MiniMax H3 Ref2VA 剪枝 int8（本機 ComfyUI） | 有聲影片＋對嘴＋首尾幀一次出；雲端 Seedance 品質相近但每秒要錢 |
| 加速 | DMAD 4 步蒸餾 LoRA＋comfy kitchen INT8 注意力 | 8 類鏡頭並排看不出差、快約一半；EasyCache 會讓近景糊 |
| 配音 | Breeze TTS 2（台灣腔參考）→ VoxCPM2（克隆生成） | VoxCPM2 直接克隆會帶大陸腔；Edge-TTS 只當聲調對照「答案卷」 |
| 挑音 | faster-whisper ASR＋自製聲調比對 | ASR 只驗字，抓不到聲調錯 |
| 配樂 | MiniMax Music 3（純器樂） | YuE2 會夾人聲，且非商用 |
| 放大 | NVIDIA RTX VSR（近景）、FlashVSR（全景） | SeedVR2、SoL-Refiner 會改臉、改嘴型 |
| 空間 | Blender 方塊人布置圖 | 不鎖空間，Image 2.5 會讓學生背對黑板、窗戶換邊 |
| 協作 | Claude Code＋專案技能＋記憶 | — |

## 不做的事（以及原因）

- **不用 Avatar 平台**（HeyGen 等）：只能做主播式講話，演不了戲。
- **不讓 H3 寫字**：中文會變亂碼，標題、名片一律後製。
- **不做全身舞蹈遠景**：768p 時臉只有幾十像素，放大救不回。
- **不用遮罩擦過去做變身**：要用光流變形或 H3 首尾幀連續變化，觀眾要看到「變的過程」。
