# 06 安裝

Windows 11＋NVIDIA 顯卡。所有路徑以 `C:\AI` 為慣例；要放別處就改各腳本頂端的路徑，或設下方的環境變數。

## 1. 資料夾慣例

```
C:\AI\
  H3\            ComfyUI＋H3 主環境（venv＋ComfyUI 程式＋models）
  Voice\         語音環境（VoxCPM2、faster-whisper、stable-ts、audio-separator、edge-tts）
  BreezeTTS\     Breeze TTS 2（程式庫 breeze-tts、權重 breeze-tts-2、獨立 venv；只用來設計角色參考音）
  BreezyVoice\   BreezyVoice（code、model、winstub、Python 3.10 venv；所有台詞配音）
  Blender\       Blender 5.x portable（預演用，選用）
  tools\         ← 把本 repo 的 tools\ 複製到這裡
```

## 2. 主環境（ComfyUI＋H3）

| 項目 | 原專案版本 |
|---|---|
| Python | 3.12.14 |
| PyTorch | 2.14.0+cu130（CUDA 13.0） |
| ComfyUI | 0.37.0（資料夾名稱是 `ComfyUI-0.36.0`，原地升級過）；**Colab 版自動裝 0.40.0＋Veda**（2026-10-16） |
| comfy-kitchen | 0.2.35（INT8 注意力、ConvRot 量化） |
| ffmpeg | 9.0.1 full build（需要在 PATH 上，含 ffprobe） |

ComfyUI 自訂節點（H3 本身是核心節點，不用裝）：
- `Nvidia_RTX_Nodes_ComfyUI`（RTX VSR）、`ComfyUI-FlashVSR_Ultra_Fast`（全景放大）
- `ComfyUI-GGUF`、`ComfyUI-KJNodes`（工具）
- 選用：`ComfyUI-Fisher-Pose`（姿勢）、`Comfyui_Minimax_h3_latent_Upscaler`（H3 精修）
- 選用（本 repo 自帶）：`setup/comfy_nodes/whitemodel_color` → 複製到 `ComfyUI/custom_nodes/`、重啟 ComfyUI。多人白模每人一個固定顏色（`make_whitemodel.py --colors red,blue`）。
- 選用（需要 ComfyUI ≥ 0.38）：`Veda-on-ComfyUI`（學習式稀疏注意力）＋`setup/downloads_veda.json` 的打分器。裝了之後 `tools/h3_shot.py` 會自動偵測：**7 秒以上的鏡頭自動開**（作者 RTX 5090 實測 12 秒鏡快 29%），短鏡（4.5 秒鏡反而慢約 10%）與有骨架／深度控制的鏡頭不開；沒裝就照原本方式跑。

- 選用（**遠景小臉精修**，`tools/face_refine.py`，2026-10-24 加入；**原頻道只在 ComfyUI 0.40＋RTX 5090 實測**，0.37 缺 FaceRefine 用到的內部函式，能跑但未實測；16GB 顯卡、Colab 未實測）：
  1. `ComfyUI-H3-FaceRefine`（MIT，commit `d8521d1`）clone 到 `custom_nodes/`。
  2. `ComfyUI-H3-NativeAudioLock`：只有 71 行、放在另一個 repo 的子資料夾、**沒有授權檔** → 本 repo 不附，請自己 clone `https://github.com/Shrek3OnVH5/MiniMax-H3-NativeAudio-MusicVideo-Workflow`（commit `11a95f6`），讀過 `custom_nodes/ComfyUI-H3-NativeAudioLock/__init__.py` 再複製進 `custom_nodes/`。作用：把原片音軌鎖進 H3 的 latent，重畫臉時嘴型跟著原音。
  3. H3 venv 加裝 `setup/env/requirements_facerefine.txt`（ultralytics、scenedetect 等；`--no-deps`，torch／numpy 不動）。注意 ultralytics 是 AGPL-3.0。
  4. 下載 `setup/downloads_facerefine.json`（FL2VA 剪枝 int8 21GB、fl2v turbo 8 步 LoRA 1.9GB、`face_yolov8m.pt` 52MB）。
  5. 重啟 ComfyUI，確認 `/object_info` 有 `H3FaceTrackCrop`、`MiniMaxH3NativeAudioLock`。用法見 `docs/02_端到端流程.md` 第 7 節。

`upscale_vsr.py` 需要的 `nvidia-vfx`、`av` 已經在 `setup\env\requirements_h3_venv.txt` 裡，照 AGENT_SETUP 裝就有；自訂節點的 requirements 不用另外裝。

啟動：`C:\AI\tools\start_comfy.cmd`（`--fast fp16_accumulation --cache-none`，127.0.0.1:8188）。

## 3. 模型下載

**實際指令以 `AGENT_SETUP.md` 第 3 節為準**（先 `cd <repo>\setup` 再跑 `download.py <清單>`，cmd 與 PowerShell 兩種寫法都有）。清單都釘了版本，每個檔都會驗證雜湊，支援續傳；已驗證過的檔案會自動跳過。下面補充 AGENT_SETUP 沒列的選用清單：

| 清單 | 內容 | 需要嗎 |
|---|---|---|
| `downloads.json` | H3 Ref2VA 剪枝 int8（19.5GiB）、官方 NVFP4 文字編碼器（14.6GiB）、影音 VAE | ✅ 必要 |
| `downloads_uncensored.json` | Qwen3-VL 32B Heretic int8 文字編碼器（24.5GiB），原專案預設 | 看 [hardware.md](hardware.md) 的模型組合 |
| `downloads_vae_int8.json` | 影片 VAE int8（2.6GiB，目視無差） | 看 [hardware.md](hardware.md) |
| `downloads_dmad.json` | DMAD 4 步 LoRA（Diffusers 格式）→ 要轉檔，見下 | ✅ 必要 |
| `downloads_action_loras.json` | Combat_V2、GunFu、Motion_Repair、速度滑桿 | 選用 |
| `downloads_swap.json` | 換角色 v1.1、換頭 v1.0（Alissonerdx，約 390MB，`h3_edit.py` 的 `recipe`） | 選用 |
| `downloads_funcontrol.json` | H3 Fun ControlNet（骨架控制）、SDPose | 舞蹈片才要 |
| `downloads_whitemodel.json` | 白模動作參考：SAM 3D Body、MoGe-3、SAM 3.1、RT-DETR v4（約 7.2GB，`tools/make_whitemodel.py`） | 舞蹈／武打照原片動作才要 |
| `downloads_qwen_turbo.json` | Qwen-Image 2.1 Turbo int8（7.3GB，`gen_image.py --turbo` 草稿模式） | 選用 |
| `downloads_facerefine.json` | 遠景小臉精修：FL2VA 剪枝 int8、fl2v turbo 8 步 LoRA、`face_yolov8m.pt`（約 23GB，`tools/face_refine.py`） | 遠景裡有要認得出的角色才要 |
| `downloads_unpruned.json` | 未剪枝 H3（31.7GiB），實測跟剪枝版無差 | 不需要 |

> `destination` 寫的是 `C:/AI/H3/models/...`，路徑不同就先改清單。

DMAD 轉檔（q/k/v 精確合併，轉完會自我驗證）：
```
C:\AI\H3\venv\Scripts\python.exe C:\AI\tools\dmad_lora_convert.py C:\AI\H3\ComfyUI-0.36.0\models\loras\dmad_raw\dmad_minimax_h3_4step_lora_critic.safetensors C:\AI\H3\ComfyUI-0.36.0\models\loras\dmad_h3_4step_lora_critic_comfy.safetensors
```

配樂 MiniMax Music 3（int8 DiT、pruned int8 文字編碼器、DAV VAE）用 `downloads_music3.json` 下載。

唱詞歌（選用，順序見 `templates/song_yue2_v14/README.md`）：
- YuE2 int8（3.96 GB，放 ComfyUI 的 `models/checkpoints`）用 `downloads_yue2.json` 下載。ComfyUI 0.37 起內建 YuE2 節點，含 melody 模式。
- ACE-Step 1.5 XL 用 `downloads_acestep.json` 下載，約 29.9 GB：xl_sft、xl_turbo 各 9.97 GB，qwen_4b 文字編碼器 8.38 GB，qwen_0.6b 1.19 GB，VAE 0.34 GB。只在 ComfyUI 0.40 實測過。

## 5. Breeze TTS 2（C:\AI\BreezeTTS）

照官方 repo 裝在獨立 venv；`tools\breeze_batch.py` 頂端寫了程式庫與權重路徑。**權重非商用**。只用來設計新角色的參考音。

## 5b. BreezyVoice（C:\AI\BreezyVoice）

台詞配音引擎，Apache-2.0。裝法見 `AGENT_SETUP.md` 2d（Python 3.10＋uv、`--no-deps` 照 `setup\env\requirements_breezyvoice_venv.txt`、Windows 用 `setup\breezyvoice\winstub` 取代 pynini）。原專案版本：程式 commit d592c9d、模型 `MediaTek-Research/BreezyVoice-300M` rev e33b502、torch 2.7.1+cu128、onnxruntime-gpu 1.23.2、transformers 4.45.2、g2pw 0.1.1（`num_workers=0`，否則 Windows 卡死）。

## 6. OpenAI Image 2.5

```
setx OPENAI_API_KEY "sk-..."
```
或把金鑰放在專案外的文字檔，設 `OPENAI_KEY_FILE` 指向它。`img25.py` 不會印出金鑰。
可調：`IMG25_QUALITY`（預設 medium）、`IMG25_REF_SCALE`（預設 0.707，參考圖縮成一半面積；角色不像時設 1 比對）。

## 7. 環境變數總表

| 變數 | 用途 | 預設 |
|---|---|---|
| `COMFY_HOST` | ComfyUI 位址（`h3_shot.py`） | `http://127.0.0.1:8188` |
| `COMFY_DIR` | ComfyUI 資料夾（`h3_shot.py`） | `C:\AI\H3\ComfyUI-0.36.0` |
| `H3_UNET` | H3 主模型檔名 | 剪枝 int8 |
| `H3_CLIP` | H3 文字編碼器檔名 | Heretic int8 |
| `H3_VIDEO_VAE` | 影片 VAE | fp16 |
| `COMFY_EXTRA_ARGS` | `start_comfy` 額外啟動參數 | 空 |
| `H3_ATTENTION` | `pytorch` 關掉 kitchen 注意力 | kitchen INT8 |
| `OPENAI_API_KEY`／`OPENAI_KEY_FILE` | Image 2.5 | — |
| `IMG25_QUALITY`、`IMG25_REF_SCALE` | Image 2.5 畫質、參考圖縮放 | medium、0.707 |

你的硬體該用哪些值，已經寫在 `configs\profile.cmd`；每次開命令列視窗先 `call configs\profile.cmd`，再執行 `tools\start_comfy.cmd`。

## 8. 字型

腳本用 Windows 內建字型：微軟正黑（`msjh.ttc`、`msjhbd.ttc`）、標楷體（`kaiu.ttf`）。
