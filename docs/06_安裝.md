# 06 安裝

Windows 11＋NVIDIA 顯卡。所有路徑以 `C:\AI` 為慣例；要放別處就改各腳本頂端的路徑，或設下方的環境變數。

## 1. 資料夾慣例

```
C:\AI\
  H3\            ComfyUI＋H3 主環境（venv＋ComfyUI 程式＋models）
  Voice\         語音環境（VoxCPM2、faster-whisper、stable-ts、audio-separator、edge-tts）
  BreezeTTS\     Breeze TTS 2（程式庫 breeze-tts、權重 breeze-tts-2、獨立 venv）
  Blender\       Blender 5.x portable（預演用，選用）
  tools\         ← 把本 repo 的 tools\ 複製到這裡
```

## 2. 主環境（ComfyUI＋H3）

| 項目 | 原專案版本 |
|---|---|
| Python | 3.12.14 |
| PyTorch | 2.14.0+cu130（CUDA 13.0） |
| ComfyUI | 0.37.0（資料夾名稱是 `ComfyUI-0.36.0`，原地升級過） |
| comfy-kitchen | 0.2.35（INT8 注意力、ConvRot 量化） |
| ffmpeg | 9.0.1 full build（需要在 PATH 上，含 ffprobe） |

ComfyUI 自訂節點（H3 本身是核心節點，不用裝）：
- `Nvidia_RTX_Nodes_ComfyUI`（RTX VSR）、`ComfyUI-FlashVSR_Ultra_Fast`（全景放大）
- `ComfyUI-GGUF`、`ComfyUI-KJNodes`（工具）
- 選用：`ComfyUI-Fisher-Pose`（姿勢）、`Comfyui_Minimax_h3_latent_Upscaler`（H3 精修）

`upscale_vsr.py` 另需 `pip install nvidia-vfx av`（H3 venv）。

啟動：`tools\start_comfy.cmd`（`--fast fp16_accumulation --cache-none`，127.0.0.1:8188）。

## 3. 模型下載

`setup/` 裡的清單都**釘了 commit 與 SHA-256**，`download.py` 支援續傳：

```
C:\AI\H3\venv\Scripts\python.exe setup\download.py setup\downloads.json
```

| 清單 | 內容 | 版本 A | 版本 B |
|---|---|---|---|
| `downloads.json` | H3 Ref2VA 剪枝 int8（19.5GiB）、**官方 NVFP4 文字編碼器**（14.6GiB）、影音 VAE | ✅ | ✅ |
| `downloads_uncensored.json` | Qwen3-VL 32B Heretic int8 文字編碼器（24.5GiB） | ✅ 原專案預設 | ❌ |
| `downloads_vae_int8.json` | 影片 VAE int8（2.6GiB，目視無差） | 選用 | ✅ |
| `downloads_dmad.json` | DMAD 4 步 LoRA（Diffusers 格式）→ 要轉檔，見下 | ✅ | ✅ |
| `downloads_action_loras.json` | Combat_V2、GunFu、Motion_Repair、速度滑桿 | 選用 | 選用 |
| `downloads_funcontrol.json` | H3 Fun ControlNet（骨架控制）、SDPose | 舞蹈片才要 | 舞蹈片才要 |
| `downloads_unpruned.json` | 未剪枝 H3（31.7GiB），實測無差 | 不需要 | ❌ |

> `destination` 寫的是 `C:/AI/H3/models/...`，路徑不同就先改清單。

DMAD 轉檔（q/k/v 精確合併，轉完會自我驗證）：
```
C:\AI\H3\venv\Scripts\python.exe C:\AI\tools\dmad_lora_convert.py dmad_minimax_h3_4step_lora_critic.safetensors C:\AI\H3\models\loras\dmad_h3_4step_lora_critic_comfy.safetensors
```

配樂 MiniMax Music 3（int8 DiT、pruned int8 文字編碼器、DAV VAE）從 ComfyUI 官方 Music 3 模板取得。

## 5. Breeze TTS 2（C:\AI\BreezeTTS）

照官方 repo 裝在獨立 venv；`tools\breeze_batch.py` 頂端寫了程式庫與權重路徑。**權重非商用**。

## 6. OpenAI Image 2.5

```
setx OPENAI_API_KEY "sk-..."
```
或把金鑰放在專案外的文字檔，設 `OPENAI_KEY_FILE` 指向它。`img25.py` 不會印出金鑰。
可調：`IMG25_QUALITY`（預設 medium）、`IMG25_REF_SCALE`（預設 0.707，參考圖縮成一半面積；角色不像時設 1 比對）。

## 7. 環境變數總表

| 變數 | 用途 | 預設 |
|---|---|---|
| `COMFY_HOST` | ComfyUI 位址（`h3_shot.py`） | `http://127.0.0.1:8188` |
| `COMFY_DIR` | ComfyUI 資料夾（`h3_shot.py`） | `C:\AI\H3\ComfyUI-0.36.0` |
| `H3_UNET` | H3 主模型檔名 | 剪枝 int8 |
| `H3_CLIP` | H3 文字編碼器檔名 | Heretic int8（版本 B 改 NVFP4） |
| `H3_VIDEO_VAE` | 影片 VAE | fp16（版本 B 改 int8） |
| `H3_ATTENTION` | `pytorch` 關掉 kitchen 注意力 | kitchen INT8 |
| `OPENAI_API_KEY`／`OPENAI_KEY_FILE` | Image 2.5 | — |
| `IMG25_QUALITY`、`IMG25_REF_SCALE` | Image 2.5 畫質、參考圖縮放 | medium、0.707 |

版本切換用 `configs\profile_A_5090.cmd`／`configs\profile_B_16GB.cmd`。

## 8. 字型

腳本用 Windows 內建字型：微軟正黑（`msjh.ttc`、`msjhbd.ttc`）、標楷體（`kaiu.ttf`）。
