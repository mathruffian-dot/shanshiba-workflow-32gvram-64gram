# 〈D-7〉製作紀錄

> 劇本：[劇本.md](劇本.md)（v2）｜提案：[敘事方向.md](敘事方向.md)｜2026-10-04 起使用者授權「直接做到好、自己審」，審核依先前影片規則（五遍自審＋常退件清單）。

## 流程與程式

| 步驟 | 程式 | 說明 |
|:---|:---|:---|
| 布置圖 | `blender/make_plan.py`、`blender/render_layouts.py` | 沿用動畫版教室 `classroom_anim_p1.blend`（只讀），13 個教室鏡；成圖鏡射（窗在學生左手邊），總覽 `blender/布置圖總覽_v1.jpg` |
| 首幀 | `gen_frames.py` | Image 2.5 medium、n=1；房間母版 `ROOM_AH`／`ROOM_XW` 先生，再當參考；直式三分割小格 768×1344 |
| 配音 | `voice_plan.py`、`voice_stage1.py`、Breeze `breeze_batch.py`、`voice_pick.py` | VoxCPM2（繁轉簡）＋Breeze 克隆各 6 候選（小雯只用 Breeze 10 候選）→ ASR 全對 → 對照 edge-tts 台灣國語參考音挑聲調最接近者 |
| H3 | `plan_h3.py`、`pipeline_gen.py` | 官方格式（`h3_shot.py`）、固定音軌（台詞＋靜音），S04／S08／S15／S20 讓 H3 自己出環境音 |
| 後製素材 | `post_fx.py` | 撕日曆字卡、咒印名片（欄內／全畫面）、手機聊天畫面、三分割灰／亮調色、角落時間字 |
| 剪接 | `assemble.py` | 三分割、三欄→四欄、配音／旁白／音效／配樂／字幕、響度 -15.5 LUFS |
| 配樂 | `music_scenes.py` | MiniMax Music 3 純器樂三段（D-7／D-1／D-0） |
| 片尾 | `ending/config.json` | 頻道片尾範本 |
| 自審 | `review.py` | 五遍：抽格／ASR／雜訊／黑格響度／切點 |

## 過程紀錄

- 首幀第一輪 31 張；S03、S13、S19 老師背後出現教室後牆（應是黑板）→ 改用「從後方」教室參考並寫明「黑板在他身後」重生；S02 小雯偏大、S15 手臂穿長袖 → 重生。
- 配音：「段考」ASR 常寫成同音同調的「斷考／斷烤」→ 列為等價（不是念錯）；V03 太快（7.3 字／秒）、V02／小雯 L02 偏慢 → 改用分數接近、語速自然的候選。
- 另一個 session 同時在用 ComfyUI 跑 H3（XA 鏡），佇列交錯，出片時間拉長。
- H3 第一輪 31 鏡（直式 768×1344 小格可行，約 2–3 分鐘／鏡）；S07 阿禾低頭後臉漂移、翹毛消失 → 改成一直面向鏡頭仍漂 → **Image 2.5 生尾幀＋首尾幀鎖定**才穩定。
- v0 自審：S15 考卷標題字型 `mingliub.ttc` 是 ExtB 字集（顯示方塊）→ 改標楷；N4 第三欄殘留名片 → 保存蓋名片前的畫面；三分割從黑畫面滑入造成黑閃 → 改成蓋在上一鏡最後一格上滑入；S19 推近 1.65 倍。
- v1 自審：S01「下週段考喔」在下課背景音裡被 ASR 聽成「斷卡」→ 台詞時背景壓到 30%、L01 改用在背景噪音下「考」仍最穩的候選並**重拍 S01**（換配音要重拍對嘴）；響度改兩段式（loudnorm＋補增益＋限幅）。
- 教訓：三師爸克隆聲的「考喔」連讀在噪音下容易被聽成「口／卡」；挑配音時可先疊場景環境音再跑 ASR（`voice_robust.py`）。`upscale_vsr.py` 不會覆寫舊檔，重拍後要先刪 `post/vsr/<id>.mp4`（assemble.py 已處理）。
