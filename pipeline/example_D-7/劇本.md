## 設計核心

| 元素 | 做法 |
|:---|:---|
| **倒數字卡** | D-7 → D-1 → D-0，撕日曆式字卡（後製） |
| **三分割畫面** | 畫面切成三直欄：左小雯、中阿禾、右阿福。**還沒開始準備的那欄是灰的**（去飽和＋壓暗），開始準備的那欄才「亮」成暖色 |
| **四字咒印名片** | 某一欄第一次亮起來的瞬間，在那一欄蓋上名片：先知先覺／後知後覺／不知不覺。結尾第四張（全畫面）：昨天才出好題 |
| **反轉：第四種人** | 出題老師前一晚才印考卷。回看線索：①D-7 小雯問「下週四嗎？」老師停了一拍才說「對」；②D-1 老師的筆電開著一片空白的文件；③D-0 老師拿著咖啡、眼睛有點紅，考卷那疊冒著一縷熱氣（觀眾以為是咖啡）；④考卷是熱的 |
| **人物互相牽動** | 小雯 D-7 晚上就把筆記傳給阿禾；阿禾 D-1 凌晨才看到 |

## 劇本

**1. 內景・教室・下課**

畫面文字（撕日曆字卡）：「段考 D-7」

下課，教室吵吵鬧鬧。同學三三兩兩聊天。阿禾在第一排正中間折紙飛機，阿福在他斜後方撕開一包零食。小雯坐在第一排靠走廊的位子，桌上攤著聯絡簿。

山獅霸出現在教室前門，手裡拿著馬克杯。

山獅霸
下週段考喔。

教室沒有人理他。只有小雯抬起頭。

小雯
老師，是下週四嗎？

山獅霸停了一拍。

山獅霸
……對。

他轉身離開。小雯低頭，在聯絡簿上一筆一畫寫下來。阿禾的紙飛機折好了。阿福把零食倒進嘴裡。

阿禾（VO）
段考，有三種人。

畫面一分為三。左欄小雯、中欄阿禾、右欄阿福。中欄和右欄褪成灰色，只有左欄是溫暖的顏色。

畫面文字（咒印名片，蓋在左欄）：「先知先覺」

阿禾（VO）
第一種，先知先覺。一週前就開始。

**2. 內景・三人的房間・夜**

三分割畫面延續。

左欄：小雯坐在書桌前，檯燈亮著。她在讀書計畫表上打勾，接著拿手機拍下整理好的筆記，按下傳送。

中欄（灰）：阿禾躺在床上打電動。

右欄（灰）：阿福抱著一大碗飯，吃得很滿足。

阿禾（VO）
第二種跟第三種，那時候還沒出現。

**3. 內景・教室・放學**

畫面文字（撕日曆字卡）：「段考 D-1」

放學，同學背起書包。山獅霸坐在講桌後面，筆電開著，螢幕的白光照在他臉上。

山獅霸
明天段考。早點睡。

阿禾拉書包拉鍊的手停住。他慢慢抬起頭，嘴巴張開。

畫面一分為三。中欄的灰色一下子褪掉，亮起來。

畫面文字（咒印名片，蓋在中欄）：「後知後覺」

阿禾（VO）
第二種，後知後覺。也就是我。

**4. 內景・阿禾房間・深夜**

畫面文字（角落小字）：「22:00」

阿禾坐在書桌前，課本、講義堆成一座小山。他深吸一口氣，捲起袖子。

阿禾（VO）
沒關係。一個晚上，夠了。

課本整頁都已經被螢光筆塗成黃色，只剩最後一行還是白的。他拿螢光筆，慢慢拖過最後一行。

畫面文字（角落小字）：「01:30」

阿禾趴在全黃的課本上，伸手拿起手機。

阿禾（VO）
跟班長借筆記好了。

手機畫面——聊天列表。最上面是「遊戲群組 999+」，下面一點是「小雯（1）」。他點開小雯。

手機畫面——「上週四 21:03」，四張筆記照片，底下一行字：「我就知道你會問。」

阿禾的臉被手機螢幕照亮，一動也不動。

阿禾（VO）
……上週四。

**5. 內景・三人的房間・深夜**

三分割畫面。

左欄：小雯的房間燈已經關了。她蓋好被子，睡得很安穩。

中欄（亮）：阿禾的檯燈亮著，他抱著頭盯著課本。

右欄（灰）：阿福抱著枕頭睡得很香，嘴角掛著口水。

阿禾（VO）
第三種人，睡得很好。

**6. 內景・教室・早自習**

畫面文字（撕日曆字卡）：「段考 D-0」

阿禾癱坐在座位上，黑眼圈很深，臉頰上有一道螢光黃的筆痕。

小雯在削鉛筆，筆一支一支排得整整齊齊。她看了阿禾一眼，嘴角輕輕翹一下，沒說話。

阿福在後面開心地吃蛋餅。

山獅霸站在講台，一手抱著一疊考卷，一手拿著咖啡，眼睛有點紅。考卷那疊上方飄著一縷白白的熱氣。他把考卷一疊一疊放到第一排的桌上。

考卷往後傳。阿福接過來，笑嘻嘻地往後傳。

阿福
又有學習單～

他低頭看自己那張。

畫面文字（考卷標題）：「第一次段考　數學」

阿福的笑容停在臉上。

阿福
……今天，段考？

畫面一分為三。右欄最後一個亮起來。

畫面文字（咒印名片，蓋在右欄）：「不知不覺」

阿禾（VO）
第三種，不知不覺。

**7. 內景・教室・段考中**

阿福把手掌平放在考卷上，愣了一下。

阿福
老師，考卷……是熱的。

山獅霸推了一下眼鏡，挑眉、半閉眼、抿嘴，一副「又來了」的表情。

山獅霸
……開始作答。

阿禾（VO）
原來，段考有四種人。

畫面從三欄擠成四欄，最右邊多出一欄——

閃回——

**8. 內景・教師辦公室・深夜**

畫面文字（角落小字）：「D-1　02:47」

辦公室只剩一盞檯燈。山獅霸一個人站在印表機旁邊，印表機一張一張吐出考卷。他打了一個長長的哈欠。

畫面文字（咒印名片，全畫面）：「昨天才出好題」

**9. 內景・教室・段考中**

回到教室。全班低頭作答，只有沙沙的寫字聲。

阿福沒有動筆。他把兩隻手掌平平貼在考卷上，閉上眼睛，笑得很滿足。

阿福
……好溫暖。

切黑。
