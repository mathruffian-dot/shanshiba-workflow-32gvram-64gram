# 代為上傳 YouTube、發臉書

預設是做好上架包、請使用者自己上傳原檔。使用者明說要我上傳或幫忙填，才照這份做。**每一次公開、每一次送出廣告自評之前都先問。**

## 為什麼通常是使用者自己傳影片

- 這台沒有 YouTube Data API 憑證。
- Claude in Chrome 的 `file_upload` 一次上限 10 MB，成片幾百 MB 傳不了；雲端硬碟裡的檔因為多重硬連結也會被拒（要先複製到暫存區）。
- 壓到 10 MB 以下再傳只在畫質損失很小時可以接受：兩段式 libx265（`-tag:v hvc1`、AAC 128k）壓好後，跟原檔算 SSIM，**< 0.97 就不要傳**，請使用者傳原檔。短片（約 1 分鐘內）才比較可能過。

## 流程：使用者傳影片、我填其餘的

1. 使用者在自己的 Chrome 上傳 mp4（Studio → 建立 → 上傳影片），關掉對話框，影片會成為草稿。
2. 我用 Claude in Chrome 開 `studio.youtube.com` 的影片清單，點那支草稿進編輯頁，填：
   - 標題、說明欄（照 `metadata.md`）。
   - 封面：對縮圖的檔案輸入框 `file_upload` 傳 `cover.png`（先複製到暫存區）。
   - 兒童內容：否。顯示進階設定 → **AI 使用：是**。標籤：貼逗號版關鍵字。儲存。
   - 字幕：字幕 → 上傳檔案 → 包含時間碼 → 對隱藏的檔案輸入框 `file_upload` 傳 srt（不要按「繼續」，那會開系統的選檔視窗）→ 完成。
3. 瀏覽權限預設維持**私人**（上傳視窗預設是「不公開」，要改）。要公開時先問使用者；改完用頁面上的文字確認真的存了。
4. **廣告自評**：送出後不能更改，送出前先問。
5. 上傳後把網址、日期、公開狀態、上架的版本寫進 `metadata.md` 的「上架紀錄」與你自己的片單或進度紀錄。

每次存完都要確認真的存了：儲存鈕變成不能按、回到內容清單看得到改過的標題與瀏覽權限。

已知的狀況：
- 使用者看不到我操作的 Chrome 視窗；視窗被遮住時截圖會逾時、對話框大小是 0 → 重新載入頁面後馬上操作，或用 JavaScript 讀狀態確認。
- 這台的 DNS 掉過一次（ping 得到、網域解析逾時）→ 等到連線恢復再繼續，恢復後先重新確認剛才那一步有沒有存進去。
- Studio 的字幕編輯器顯示的時間是「秒：格」，不是「分：秒」，不要看錯。

## 臉書

- 貼文本文不放連結，連結全部放第一則留言。教學片可以再發「一則一活動」的圖片留言（截圖＋兩三句玩法＋連結）。
- 影片超過 10 MB 要請使用者自己拖進發文框（先複製到 Downloads、給短檔名）。臉書會把影片轉成 Reel。
- 發文框預設「已關閉 AI 標籤」，要手動打開。
- Reel 的縮圖可以用「上傳」換成封面（PNG 先複製到暫存區）。
- 貼圖到留言：內建瀏覽器傳不了圖，用 Claude in Chrome `file_upload` 對留言框的隱藏檔案輸入框傳。
- 編輯 Reel 本文：從粉專首頁那則貼文的「⋯ → 編輯貼文」；儲存後會跳出推廣視窗，按「稍後再說」，等存完再離開。
- 發佈後到 Business Suite「內容 → 已發佈」確認（大檔會顯示處理中）。
