# 封面

每支片做 3 張給使用者選，1280×720。下面是作者頻道的現行做法，頻道形象的部分換成你自己的。

## 共同做法

- **先看舊的**：同一個系列或相近題材已經採用的封面至少看一張，版面與用字照它的路線走；頻道有自己的封面慣例文件就先讀。
- **工具**：作者用 Image 2.5（品質 medium、多張同時生）。換成會花錢的管道之前先問使用者。
- **字怎麼放**，兩種都在用，看版面：
  - 字寫在提示詞裡同次生成（真人主持人的人物封面）。提示詞寫明 **Taiwan standard character forms**；每段字寫「each phrase appearing only once」；小框裡寫「no writing inside any window or card」。
  - 底圖不寫字，字用程式（PIL）疊上去（系列片的固定版面、學科圖、短劇大字）。字型用粗黑體（作者用源石黑體粗體）。
- **每張都要檢查四件事**，不合格就淘汰重生，不要修圖：
  1. **字**：逐字對，含字形。Image 2.5 會畫日本異體字（「說」畫成「説」）；多一個頓號或引號、小字壞掉都算錯。
  2. **手**：手指數、多一隻手、**左右手反了**（伸手指人的手最容易畫反 → 封面避免伸手指人，改成兩手抱道具）。
  3. **臉**：跟定妝照或形象照對。
  4. **縮圖**：縮到 320×180，主標還看得清楚。
- **交付**：選定的存 `<片>/youtube/cover.png`；三張留 `cover_A/B/C` 或 `alternates/`；另做一張三張並排加手機縮圖的總覽圖給使用者選；`cover-notes.md` 或 `metadata.md` 的「封面」節寫每張的主標、畫面、為什麼建議、缺點、使用者選了哪張，以及重做時需要的東西：用哪個模型、提示詞與生成腳本在哪、淘汰掉的是哪幾張與原因。頻道另有集中放上架包的資料夾就同步一份過去。
- 還沒選之前，`cover.png` 先放我推薦的那張，並在 `metadata.md` 寫明「使用者還沒選」。

## 教學、說明片、直播的頻道（真人主持人）

- 人物：主持人的固定形象（同一套眼鏡、服裝）。參考圖附兩張：正式形象照（臉）、同頻道一張採用過的封面（只借版面，提示詞寫明不抄字和配色）。
- 版面：接近純黑背景＋白字＋單一主題強調色；人物在右、主標兩行在左；左上系列標籤、右上集數、右下圓章（例「FREE 免費」）。
- 每個概念 2 張，逐字檢查後挑 3 張給使用者。
- 同一集已經有封面就沿用。

## 系列片（例：一套五集的課程）

系列名或「免費課程」比單集的梗更能吸引人點進來，所以：

- 最大的字是**系列名**（加「免費」章），接「第 N 集」徽章，本集的鉤子放副標。
- 預設版面：上方「系列名＋免費章」、「第 N 集」徽章、**片中真實畫面**做成斜放的卡片、下方黃色帶寫主題。
- 主題帶傾向用大家會搜的說法（「AI ＿＿全攻略」），卡片上的字跟 ★1 標題呼應。
- 做法：Image 2.5 生不含字的底圖，字與卡片用 PIL 疊。照樣給 3 張。

## 學科歌、解說片

- 封面要有**主題本身的圖**（例：真的元素週期表），最大的字是它**大家會搜的名字**（「元素週期表」），俏皮的鉤子排第二。
- 主題圖用程式畫，不要叫 Image 2.5 畫（它畫的週期表把亮格放錯排）。Image 2.5 只畫人物和空白板子。
- ★1 標題用同樣的詞。

## 短劇、對決、MV 的頻道（片中角色）

- 一張佔畫面 40% 以上的誇張大臉、單一焦點、高飽和高對比；底圖不寫字，疊 6 字內的大字。
- 字要有懸念，不要只描述劇情（例：「老師也用AI？」）。
- 不要雷到結局；笑點在開頭一分鐘的梗不適合當主封面。
- 畫面裡不要有旗子、多餘的字；識別證之類留空白。
