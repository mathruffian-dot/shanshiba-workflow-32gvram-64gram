# 短劇審閱與修改清單

## 輸出格式

每個問題固定四段，依**影響程度**排序：

1. **問題**：具體指出失效之處。
   - **依據**：對應的場次、節拍或臺詞。
   - **影響**：為何妨礙理解、情緒或節奏。
   - **修改**：可執行的修正方向。

最後列「**建議保留**」——只列真正有效、修改時應該保住的元素。不要用空泛稱讚取代診斷。

---

## 題材與觀眾

- [ ] 題材、核心前提與目標觀眾清楚且彼此相符。
- [ ] 類型承諾在**前 15 秒**就能被觀眾辨識。

## 結構與節奏

- [ ] 有明確的鉤子、推進、反轉、收尾，各節拍秒數對得上目標長度。
- [ ] 沒有重複或停滯段落——1–2 分鐘的篇幅撐不起鋪陳。
- [ ] 單支獨立成篇，沒有莫名其妙的「下集待續」。

## 角色動機與連貫性

- [ ] 山獅霸的行為符合既定人設（沉穩、看穿事情、話不多但一針見血），沒有為劇情把他寫成暴躁或囉嗦。
- [ ] 角色的選擇由已建立的目標、壓力或新事件支撐。
- [ ] 角色轉變有連續的可見行動與代價。

## 場次與衝突

- [ ] 每場有角色目標與阻力，並改變資訊、關係、目標、風險或情緒之一。
- [ ] 衝突隨場次推進而升級，不只由角色說明。

## 臺詞與潛臺詞

- [ ] 臺詞符合角色關係與當下目的，不是解說背景。
- [ ] 關鍵資訊盡量由行動、反應、迴避或試探承載。
- [ ] 山獅霸的臺詞夠短。
- [ ] 台詞總字數對得上該場秒數（**實測約每秒 5.5 字**）。
- [ ] **台詞密度撐得起片長**：台詞總秒數 ÷ 片長 ≥ 20%。低於這個數字通常是戲太稀、在靠氣氛硬撐——而每一秒空鏡都要付生成費。

## 反轉與收尾

- [ ] 反轉有前文線索，回看時合乎人物與因果。
- [ ] 收尾帶來餘味、新問題或不可逆代價，不是單純中斷事件。

## 技術可行性（Seedance 2.5）

> 這一區不通過就要**改劇本**，不能留給後製。

- [ ] 沒有快速動作、打鬥、追逐、劇烈鏡頭運動（會 morphing）。
- [ ] 同一時間只有一個人說話，沒有搶話或多人同時對白。
- [ ] 每場能在 30 秒內講完；講不完的已拆場。
- [ ] 場景數在創作簡報的上限內，沒有偷加。
- [ ] 有台詞的新角色數量克制——每個都要多做一組參考圖。
- [ ] 天馬行空放在**設定與情境**的奇特，不是動作場面。

## 16:9 構圖語言

- [ ] 有用到寬景或環境敘事，沒有浪費橫式的空間。
- [ ] 特寫克制，中景與中特寫是主力。
- [ ] 沒有出現「角色塞滿畫面」這種直式構圖邏輯。
- [ ] 沒有寫鏡號、景別代號、運鏡或影片模型參數。

## 格式與最終修改

- [ ] 場次標頭皆含場次、內景／外景、地點、時間，地點名稱跨場一致。
- [ ] 短片標題、角色名稱、臺詞與畫面文字格式一致；主角一律寫「山獅霸」。
- [ ] 修改優先處理妨礙理解、情緒或節奏的問題，並保留有效元素。

## 片段切分（若已進到第 9 階段）

- [ ] 每段 ≤30 秒，實務落在 20–25 秒。
- [ ] 沒有切在台詞中間、連續動作中間或反轉揭露的瞬間。
- [ ] 同一段內沒有換場景。
- [ ] 每段都指定了參考圖；有臉部戲的段落含 `v8_C_face`。
- [ ] **沒有把 `v8_D_expressions` 六格表情表列為參考圖。**
- [ ] 每段都寫了五項齊全的 LoRA caption。
