# 短劇審閱與修改清單

> **使用者叫修過的問題，都是下次自審的標準（使用者 2026-11-02）**：修完當下補進這份清單，交片前逐條過。

## 輸出格式

每個問題固定四段，依**影響程度**排序：

1. **問題**：具體指出失效之處。
   - **依據**：對應的場次、鏡號、節拍或臺詞。
   - **影響**：為何妨礙理解、情緒或節奏。
   - **修改**：可執行的修正方向。

最後列「**建議保留**」——只列真正有效、修改時應該保住的元素。

## 題材、主題與觀眾

- [ ] 有一句**主題錨點**，每場都能回扣。
- [ ] 一般觀眾（或系列指定觀眾）不需要背景知識；需要的背景在前 15 秒用字卡／一句旁白交代。
- [ ] 第一個畫面就是鉤子（0–3 秒）。
- [ ] **入戲表**：人物、場景、故事各有「觀眾熟悉的」＋「哪裡不對勁」；有一句具體的「這就是我」（目標觀眾真的遇過的情境）。
- [ ] 0–3 秒有看得懂的衝突＋一個觀眾會想問的問題；**衝突要快、答案要慢**（答案不在開頭）。
- [ ] **前 3 秒靜音測試**：只看第一、二格（不看字幕、不聽聲音）說得出誰、在哪、哪裡不對勁。

## 結構、預期曲線與情緒流

- [ ] 有鉤子、推進、反轉、收尾，秒數對得上目標長度。
- [ ] 節拍表的「觀眾此刻以為」欄每格都填了；**每個轉折都寫得出被哪句台詞或哪個畫面翻掉**。
- [ ] 相鄰節拍情緒不同；全片有一個明確轉調點。
- [ ] 沒有重複或停滯段落；但轉折後有一拍反應，不是一路衝到底。

## 角色

- [ ] 既有角色符合人設（照你的角色設定檔；系列角色照 `系列設定.md`）。
- [ ] 有成長弧的角色寫了 Want／Need／Lie／Flaw／Ghost，結尾回應「Lie 動搖了沒」。
- [ ] 角色轉變有可見行動與代價支撐。
- [ ] 有台詞的新角色數量克制。

## 場次與因果鏈

- [ ] 每場有目標與阻力，並改變一件事。
- [ ] 場與場之間是「因為…所以」；**沒有只能寫成「然後」的接縫**。

## 臺詞

- [ ] 臺詞推進衝突或關係；轉折與隱喻有一句講白。
- [ ] 山獅霸臺詞夠短；梗一聽就懂，沒有冷門雙關。
- [ ] **台詞和前後畫面對得上**：提到的動作先演出來、數量一致、「他／她」指誰清楚、反應緊接動作。
- [ ] 時代細節對（例：〈AI研習宇宙〉2022–2023 沒有 B5 生成式 AI 課程）。
- [ ] TTS 用字查過讀音修正表。
- [ ] **文言破音字**：先查教育部辭典，**整句查不到要再查單字條目的書證**（使用者 2026-11-03，「吾與點也」整句沒收，「與」ㄩˇ 的書證就引這句）；都沒標音才列給使用者定，定了補進讀音修正表。聽寫只驗字、驗不出聲調，關鍵字另量 F0 或請人聽。
- [ ] **片中給的具體做法要有依據**：時段、窗口這類內容法規沒寫就不編成像真的；先列出這個情境實際會發生什麼事，答案要對題；提問的角色要得到答案、要有反應，答案要有人講出來。
- [ ] **題材有相關新聞就先查**：寫劇本前搜最新政策與新聞，官方用語照引原話；哪些是戲劇誇張寫在說明欄，上片前再查一次。
- [ ] **全圖閃爍**：H3 的 Veda 不開（會讓整個畫面在第 51／119／187 格閃一下）；成片逐格量亮度，0 閃才能交。

## 反轉與收尾

- [ ] 反轉有前文線索（列出鏡號），回看合乎人物與因果。
- [ ] **翻盤用的關鍵詞（身分、名稱、真相）在翻盤前沒有出現**（字幕、面板、道具字、內心都算）；開場用模糊說法代替（使用者 2026-10-15，〈AI研習宇宙〉Ep6「一開始就說承辦，爆了後面的梗」）。
- [ ] 每個「為什麼要這樣做」都有一句台詞或畫面講白後果（例：講師不來→下午三小時不算→所以要找人上台）；意義不明的動作配一句說明。
- [ ] 收尾是人物選擇的後果，有餘味或問題。

## 技術可行性（Image 2.5＋本機 H3）

> 不通過就**改劇本**，不留給後製。

- [ ] 每鏡 ≤12 秒；一鏡最多一兩句台詞；同一時間只有一個人說話。
- [ ] 主角腰上以上；全身舞蹈／武打等照原片動作的鏡頭：白模動作參考（make_whitemodel.py，2026-10-14 起取代骨架）＋尾幀，見舞蹈踩坑文件。
- [ ] **場景裡的字（手機、筆電、大螢幕、投影、招牌、紙箱、福袋）由 Image 2.5 畫進首幀**，不後製疊（會跟背景不搭，使用者 2026-10-13）；H3 動起來會扭曲字就改靜態鏡或首尾幀鎖同一張。只有系統面板（HUD）、字幕、全螢幕靜態插入可以後製疊。
- [ ] 道具不憑空出現／消失；數量與物理位置合理。
- [ ] 每鏡只放要演戲的人；上課場景背景有同學、背景人坐著幾乎不動。
- [ ] 教室空間：黑板在前、學生面向黑板、窗在學生左手邊；老師不碰學生。
- [ ] 首幀看不到臉、之後才轉正臉的鏡已標尾幀鎖。
- [ ] 場景數在上限內。

## 構圖

- [ ] 9:16：多人用縱深、上下錯開；字卡在上半部且不擋臉、避開 Shorts 說明區。
- [ ] 16:9（指定時）：有用到寬景，特寫克制。
- [ ] 畫面夠豐富：有反應鏡、插入鏡、推近、同步動作等。
- [ ] **一個人連講超過約 30 秒要插反應鏡（使用者 2026-11-04，第 7 集 v2）**：畫面一直是同一人，節奏會平；插 1–2 個聽者反應鏡（無台詞、約 2.5 秒），優先選後面有戲的人，順便替後面的轉折鋪陳。
- [ ] **畫面上要讀的字要念出來（使用者 2026-11-03，第 6 集 v1）**：單子、字卡、手機訊息、古文，超過約 8 個字（書名出處不算）就要有人念，**鏡長跟念的長度一致**，不要讓觀眾自己看；自審工具 第 ⑦ 項會列出沒人念的長字卡。
- [ ] **真實案例不能只講結論（使用者 2026-11-03：「繞路載上學，刁難請假，這是什麼意思，我看不懂」）**：投訴、新聞、規定的句子，要讓第一次聽的人知道前因（誰要做什麼、老師做了什麼）才接結論；需要時拆成「前因—角色回應—結論」三鏡。
- [ ] **沒台詞的鏡，背景不准自己冒人聲（使用者 2026-11-03）**：soundscape 不寫任何人的說話、念書聲（H3 會生出來路不明的聲音）；劇情要有誰的聲音，就拍那個角色念，只取聲音疊上去（`cut_config.vo`）。
- [ ] **破音與多音字要看片中整句（使用者 2026-11-03：排擠的「擠」念錯，聽寫抓不到）**：聽寫對不代表聲調對；句尾關鍵字量音高，再查讀音修正表。
- [ ] **聽寫只差一個字也要看（使用者 2026-11-03：「載」念成「宰」，相似度 0.84 過了門檻）**：聽寫結果跟字幕逐字比對，不同的字逐條判斷，同音字放過、破音字念錯就重抽；自審有懷疑的字，交片訊息一定要列出來。
- [ ] **聲音和畫面不能累積偏移（2026-11-04）**：修剪到鏡尾時來源可能少 1 格，每少 1 格後面全部錯開。剪接工具要補足缺格並比對總格數；字幕掛到下一鏡就是徵兆。
- [ ] **背景有門口、空地就會冒人，鎖尾幀也擋不住（2026-11-04）**：連 3 個 seed 都冒就改首幀，背景只留牆。
- [ ] **畫外念白也要聽寫（使用者 2026-11-03：1:44「欲」念成「又」，念白不在整片聽寫表裡，自審沒查到）**：畫外念白的聲音來源也要逐字比對、逐條判斷；同一個字在別鏡念對，不代表這鏡也對。
