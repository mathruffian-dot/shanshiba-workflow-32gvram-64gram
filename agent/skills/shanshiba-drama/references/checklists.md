# 短劇審閱與修改清單

> **使用者叫修過的問題，都是下次自審的標準（使用者 2026-11-02）**：修完當下補進這份清單，交片前逐條過。

## 輸出格式

每個問題固定四段，依**影響程度**排序：

1. **問題**：具體指出失效之處。
   - **依據**：對應的場次、鏡號、節拍或臺詞。
   - **影響**：為何妨礙理解、情緒或節奏。
   - **修改**：可執行的修正方向。

最後列「**建議保留**」——只列真正有效、修改時應該保住的元素。

## 題材、主題與觀眾

- [ ] 有一句**主題錨點**，每場都能回扣。
- [ ] 一般觀眾（或系列指定觀眾）不需要背景知識；需要的背景在前 15 秒用字卡／一句旁白交代。
- [ ] 第一個畫面就是鉤子（0–3 秒）。
- [ ] **入戲表**：人物、場景、故事各有「觀眾熟悉的」＋「哪裡不對勁」；有一句具體的「這就是我」（目標觀眾真的遇過的情境）。
- [ ] 0–3 秒有看得懂的衝突＋一個觀眾會想問的問題；**衝突要快、答案要慢**（答案不在開頭）。
- [ ] **前 3 秒靜音測試**：只看第一、二格（不看字幕、不聽聲音）說得出誰、在哪、哪裡不對勁。

## 結構、預期曲線與情緒流

- [ ] 有鉤子、推進、反轉、收尾，秒數對得上目標長度。
- [ ] 節拍表的「觀眾此刻以為」欄每格都填了；**每個轉折都寫得出被哪句台詞或哪個畫面翻掉**。
- [ ] 相鄰節拍情緒不同；全片有一個明確轉調點。
- [ ] 沒有重複或停滯段落；但轉折後有一拍反應，不是一路衝到底。

## 角色

- [ ] 既有角色符合人設（照你的角色設定檔；系列角色照 `系列設定.md`）。
- [ ] 有成長弧的角色寫了 Want／Need／Lie／Flaw／Ghost，結尾回應「Lie 動搖了沒」。
- [ ] 角色轉變有可見行動與代價支撐。
- [ ] 有台詞的新角色數量克制。

## 場次與因果鏈

- [ ] 每場有目標與阻力，並改變一件事。
- [ ] 場與場之間是「因為…所以」；**沒有只能寫成「然後」的接縫**。

## 臺詞

- [ ] 臺詞推進衝突或關係；轉折與隱喻有一句講白。
- [ ] 山獅霸臺詞夠短；梗一聽就懂，沒有冷門雙關。
- [ ] **台詞和前後畫面對得上**：提到的動作先演出來、數量一致、「他／她」指誰清楚、反應緊接動作。
- [ ] 時代細節對（例：〈AI研習宇宙〉2022–2023 沒有 B5 生成式 AI 課程）。
- [ ] TTS 用字查過讀音修正表。
- [ ] **文言破音字**：先查教育部辭典，**整句查不到要再查單字條目的書證**（使用者 2026-11-03，「吾與點也」整句沒收，「與」ㄩˇ 的書證就引這句）；都沒標音才列給使用者定，定了補進讀音修正表。聽寫只驗字、驗不出聲調，關鍵字另量 F0 或請人聽。
- [ ] **片中給的具體做法要有依據**：時段、窗口這類內容法規沒寫就不編成像真的；先列出這個情境實際會發生什麼事，答案要對題；提問的角色要得到答案、要有反應，答案要有人講出來。
- [ ] **題材有相關新聞就先查**：寫劇本前搜最新政策與新聞，官方用語照引原話；哪些是戲劇誇張寫在說明欄，上片前再查一次。
- [ ] **全圖閃爍**：H3 的 Veda 不開（會讓整個畫面在第 51／119／187 格閃一下）；拍完跑 `tools/flashcheck.py --clips <資料夾>`，0 閃才能交。
- [ ] **整片聽寫的 ⚠ 句子要逐句回單鏡判斷**：整片聽寫常把前後鏡的聲音併進來或漏掉短句；每句 ⚠ 都對單鏡重聽寫（加逐字時間），關鍵字再看聲調（F0），自審報告逐句寫結論（修了／不用修＋理由／要人聽）。
- [ ] **混音兩項**：①原聲關掉（gain 0）的鏡是數位全靜，要墊同場底噪（`roomtone`）；②沒台詞的笑聲、掌聲鏡不可比台詞大聲（`gain` 約 0.45＋`afade` 淡出）。
- [ ] **同一鏡聽到兩個聲音**：逐鏡聽有沒有疊音、回音、第二個人跟著念；限制句的性別要跟說話的人一致。聽寫看不出來，要聽或看頻譜。
- [ ] **新配角的參考音要先給使用者聽過才拍**：`voice_profile.json` 寫「待使用者聽」的，交片前一定要問。
- [ ] **笑聲、嘆氣也要用角色參考音**：沒台詞但會出聲的鏡，寫一句「呵呵」之類掛 `voice_ref`，字幕給空字串；不要讓 H3 自己配一個陌生人的笑聲。
- [ ] **只在聽的人嘴不能動**：H3 會讓臉部特寫的人自己講話；只聽不說的鏡一律給 `audio.fixed` 靜音檔，嘴才會閉著。
- [ ] **道具連戲：講電話的整段每一鏡都要拿著電話**：通話中每一鏡的首幀都要畫電話在耳邊，直到掛掉。
- [ ] **同場髮型、帽子逐鏡比對**：首幀提示詞不要寫「hair loose」這種會改髮型的字；同場每張首幀並排看一次。
- [ ] **同一句裡不要連用兩次否定詞，也不要出現相鄰重字（例如「沒有有」）**：觀眾會聽成念了兩次。寫台詞時唸一遍，聽起來像口吃的就改寫。
- [ ] **背對鏡頭的鏡要查左右手**：從背後拍時模型常把左手畫成右手（拇指方向反了）。不演戲的那隻手藏進袖子／口袋，首幀寫明只看得到哪一隻手，抽格時放大看手。
- [ ] **換了某一鏡的版本後，字幕時間要重算**：沿用舊版的開口時間，燒入字幕會提早出現或提早消失。交片前逐鏡比對字幕時間和實際開口時間（音量 > −30 dB），差 > 0.6 秒就修。
- [ ] **成片每秒一格審**（`tools/framecheck.py`）：背景突然冒人、臉或手糊掉、道具不連戲、牆上冒旗子都要修，沒修的鏡頭不能用。
- [ ] **H3 自己切鏡會切到掛旗子的教室**（2026-11-06 補）：沒台詞的短反應鏡最常發生，常切到牆上掛旗子、貼紅色標語的教室。限制句加「no flags, banners or national emblems」；用 `tools/clipcheck.py` 抓（跟首幀相關係數 < 0.7 要看）；台詞講完才切就剪掉，否則尾幀鎖首幀重抽。
- [ ] **soundscape／setting 不寫人群**（2026-11-06 補）：crowd、chatter、murmuring、students 這類字會讓 H3 把人畫進背景，鎖尾幀也擋不住。
- [ ] **稱呼後面的逗號會停約 1 秒**（2026-11-06 補）：H3 念「老師，」常在逗號停一下。要連著念就把 H3 輸入的逗號拿掉，字幕再補回去。
- [ ] **台詞開頭不要放「……」**（2026-11-06 補）：H3 會在那段空白念亂語。要停頓就改「嗯，」，動作寫嘴巴閉著（lips closed）的停頓。
- [ ] **背景沒人的鏡，動作句不要寫「背景的人保持小動作」**：舊的通用動作句會把人叫進背景；背後改成牆或門塞滿。
- [ ] **走路、移動鏡用 14 步、正常步速**：快走會讓腿和袍子糊掉；不是重點就別寫 fast。
- [ ] **連續講話的跳切**：同一人、同構圖接連兩鏡，後一鏡用 `punch` 放大 20%（以臉為中心）；畫面本來就很緊、放大會切到頭的，才換鏡位重拍。`review_ep.py` ④d 會列出。
- [ ] **montage／主題曲段落把 H3 原聲關掉**：H3 會自己生含糊的人聲。
- [ ] **配樂不要在兩句之間彈回來**：空檔不到 1 秒時，配樂壓低後放開又壓，會變成「噗」一聲；`assemble_ep.py` 已把短空檔一起壓住。接點音量跳 >20 dB 要量是原聲還是配樂。
- [ ] **時間跳躍字卡（〈十年後〉）要大、置中**：預設 64 號字太小，用 120 號。
- [ ] **片中引用的經典、成語、真實事件，自己要能講出處**：出處寫在劇本的實際案例表，上架時放說明欄。

- [ ] **雙語片先列每個角色講哪種語言（〈One Minute with Mina〉使用者：「在腳本裡面，學生是說英文，不是說韓文」）**：寫鏡表前列一張「角色—語言—講幾次」的表給使用者確認，不要把「所有對話」套到每個角色。

- [ ] **特寫的 setting 不寫大場面（〈Make Our Own Light〉自審）**：setting 寫「巨型舞台」時，6 個特寫鏡兩個 seed 都被 H3 拉成遠景、冒伴舞、換衣服、冒旗子。特寫 setting 只寫眼前失焦的背景，限制句寫不准拉遠、舞台地板與伴舞不出現，重拍 7 鏡全部穩住。

## 構圖

- [ ] 9:16：多人用縱深、上下錯開；字卡在上半部且不擋臉、避開 Shorts 說明區。
- [ ] 16:9（指定時）：有用到寬景，特寫克制。
- [ ] 畫面夠豐富：有反應鏡、插入鏡、推近、同步動作等。
- [ ] **一個人連講超過約 30 秒要插反應鏡（使用者 2026-11-04，第 7 集 v2）**：畫面一直是同一人，節奏會平；插 1–2 個聽者反應鏡（無台詞、約 2.5 秒），優先選後面有戲的人，順便替後面的轉折鋪陳。
- [ ] **手要連到肩膀（使用者 2026-11-04，第 7 集 v2）**：逐鏡看手不只數手指，也要看肩膀→袖子→前臂→手是不是同一隻手、手是不是從人在的那一側進畫面；袖子不能跟手分開垂著。
- [ ] **劇中職務查實際歸屬（使用者 2026-11-04，第 7 集 v2）**：每項工作、每個職稱都查過通常歸哪個單位（學校用處務規程、職掌表），不存在的職稱不用；不是主角的工作要講白為什麼落到他頭上。
- [ ] **畫面上要讀的字要念出來（使用者 2026-11-03，第 6 集 v1）**：單子、字卡、手機訊息、古文，超過約 8 個字（書名出處不算）就要有人念，**鏡長跟念的長度一致**，不要讓觀眾自己看；自審工具 第 ⑦ 項會列出沒人念的長字卡。
- [ ] **真實案例不能只講結論（使用者 2026-11-03：「繞路載上學，刁難請假，這是什麼意思，我看不懂」）**：投訴、新聞、規定的句子，要讓第一次聽的人知道前因（誰要做什麼、老師做了什麼）才接結論；需要時拆成「前因—角色回應—結論」三鏡。
- [ ] **沒台詞的鏡，背景不准自己冒人聲（使用者 2026-11-03）**：soundscape 不寫任何人的說話、念書聲（H3 會生出來路不明的聲音）；劇情要有誰的聲音，就拍那個角色念，只取聲音疊上去（`cut_config.vo`）。
- [ ] **破音與多音字要看片中整句（使用者 2026-11-03：排擠的「擠」念錯，聽寫抓不到）**：聽寫對不代表聲調對；句尾關鍵字量音高，再查讀音修正表。
- [ ] **聽寫只差一個字也要看（使用者 2026-11-03：「載」念成「宰」，相似度 0.84 過了門檻）**：聽寫結果跟字幕逐字比對，不同的字逐條判斷，同音字放過、破音字念錯就重抽；自審有懷疑的字，交片訊息一定要列出來。
- [ ] **聲音和畫面不能累積偏移（2026-11-04）**：修剪到鏡尾時來源可能少 1 格，每少 1 格後面全部錯開。剪接工具要補足缺格並比對總格數；字幕掛到下一鏡就是徵兆。
- [ ] **背景有門口、空地就會冒人，鎖尾幀也擋不住（2026-11-04）**：連 3 個 seed 都冒就改首幀，背景只留牆。
- [ ] **畫外念白也要聽寫（使用者 2026-11-03：1:44「欲」念成「又」，念白不在整片聽寫表裡，自審沒查到）**：畫外念白的聲音來源也要逐字比對、逐條判斷；同一個字在別鏡念對，不代表這鏡也對。

- [ ] **動作不能卡住**（〈人不知〉MV 使用者：「3 秒，動作卡住」）：首幀畫在跨步中間，H3 只會定在那個姿勢晃。走路鏡首幀畫站定、雙腳併攏，action 逐步寫步數；交片前看腳有沒有真的交替（光流檢查抓不到這種）。
- [ ] **身體和脖子要合人體工學**（〈人不知〉MV 使用者：「身體脖子違反人體功學」）：不要背對鏡頭卻把頭轉過肩膀。要回頭的鏡，首幀全身側面，action 寫腳、腰、肩、頭一起轉；首幀就檢查頭和肩的夾角不超過約 90 度。
- [ ] **畫面意象要說得通**（〈人不知〉MV 使用者：整棟樓窗戶一格格亮「不合理」）：比喻鏡也要過「現實裡為什麼會這樣」。夜裡空教室整棟亮燈說不通；要講「大家都還亮著燈」，就拍每個人各自在燈下做事，全景只留零星自然亮著的窗。

- [ ] **手機、相機方向要對**（〈人不知〉MV 使用者：「學生手機拿反了」）：拍攝的人，鏡頭朝被拍者、螢幕朝自己。首幀寫清楚，最好從拍攝者身後拍，讓螢幕朝鏡頭、螢幕裡看得到被拍者；光寫 back of the phone toward the camera 會反。
- [ ] **作揖、握手這類手部特寫要避開**（〈人不知〉MV 使用者：「孔子握拳的手怪怪的」）：寫 clasped hands 會畫成拳頭頂在胸前。古裝行禮把雙手收進併攏的袖子裡，首幀就看不到手指。

- [ ] **轉身不能換臉**（〈人不知〉MV 使用者：「2:38 人臉跑掉」）：首幀是側面、片中才轉正臉，一定鎖尾幀（Image 2.5 另做正面完成姿勢）；首幀盡量看得到兩隻眼睛。審片要比首尾兩格是不是同一人。
- [ ] **窗內、房間深處會冒人**（〈人不知〉MV 自審）：窗內拍人身後留房間，連續三次有人走過；身後貼拉上的窗簾才乾淨。靜態空景拍超過 4 秒也可能自己跳別的場景，逐鏡看。
- [ ] **閉口音長音不硬拍對嘴**（〈人不知〉MV 自審）：「燈」這類字 H3 會閉著嘴唱；唱到那個字就切到歌詞講的畫面。
- [ ] **進片尾要有鋪陳**（〈人不知〉MV 使用者：「最後接結尾畫面太突然，不順」）：最後一句台詞後留一拍，音樂先淡入鋪墊，畫面用溶接；結尾畫面也要溶進去，字慢慢出來、跟音樂一起收。
- [ ] **試聽要放到會被影響的段落**（〈人不知〉MV 使用者：重唱版「副歌跟上一版不太一樣，上一版比較好聽」）：我只放接點前後 25 秒，連續重唱版後面整段都換了，使用者選的時候根本沒聽到副歌。比方案時，每個方案會改到的段落都要放進試聽。
