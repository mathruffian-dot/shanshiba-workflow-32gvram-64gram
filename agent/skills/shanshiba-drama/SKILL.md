# 山獅霸 AI 短劇編劇

## 開工前必讀（不可跳過）

1. `角色資產/山獅霸/角色設定.md` — 角色核心、四個一致性錨點，特別是**第七節〈劇本寫作約束〉**
2. 專案 `CLAUDE.md` 的〈影片規格〉段

角色外型與提示詞一律**引用設定檔**，不要在劇本裡自己重寫角色描述。

## 本專案的固定規格

| 項目 | 值 |
|:---|:---|
| 畫面比例 | **16:9 橫式**——不是豎屏，不要套直式構圖邏輯 |
| 單支長度 | 1–2 分鐘，**獨立成篇**，沒有連續劇集數 |
| 片段上限 | **30 秒／段**（Seedance 2.5 單次上限） |
| 幀率 | 24 fps |
| 配音 | **自己配**（voice-clone 技能），不用模型生成語音 |

## 判斷任務

- **完整一支短片**：讀 `references/workflow.md`，從創作簡報一路走到片段切分。
- **單點創作**（只要題材／結構／某一場／台詞／反轉）：讀 `references/workflow.md` 的對應階段，**只交付使用者指定的成果**，不重做整支。
- **寫劇本或要格式**：讀 `references/format.md`。
- **切分片段**（劇本已存在）：讀 `references/segmentation.md`。
- **審閱或修改**（不含單點創作）：讀 `references/checklists.md`；需要格式判斷時再讀 `references/format.md`。

## 共同規則

- 只詢問會實質改變結果的缺漏；其餘採合理假設並**清楚標示**。
- 保留使用者指定的長度、類型、觀眾、場景與交付形式。
- 優先寫現在正在發生的**可見行動**，避免用說明性對白代替戲劇事件。
- 每場至少改變資訊、關係、目標、風險或情緒之一。
- 反轉必須能由前文線索回看成立；結尾要留下餘味或一個問題，不是單純中斷。
- **技術約束就是寫作約束**（詳見角色設定檔第七節）：避開快動作／打鬥／追逐；單一說話者優先；天馬行空放在**設定與情境**，不是動作場面。
- 使用者只要劇本時，**不輸出**景別、運鏡或 Seedance 提示詞——那是 `seedance` 技能的事。

## 輸出契約

**創作任務**：必要假設 → 指定創作成果 →（完整一支短片才附）片段切分表。

**審閱任務**：依影響程度排序的診斷、對應具體段落的證據、可執行的修改方向；只有能說明修正或使用者明確要求時才提供改寫。
