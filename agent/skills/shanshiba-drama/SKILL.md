# AI 短劇編劇

> **本 repo 版本說明（2026-10-23 更新，優先於 references 裡的舊說法）**
> - 角色是**你自己的角色**：references 提到的「山獅霸」「阿福」「〈AI研習宇宙〉」是原頻道的例子，本 repo 沒附角色資產。請先照 `docs/07_本地角色與首幀.md` 做好角色定妝照與參考音，把每個角色的外觀描述（年齡、臉、髮型、眼鏡、上衣與下半身）寫進你專案的角色設定檔，劇本與提示詞都引用它。
> - 影片模型是**本機 MiniMax H3**（每鏡 ≤12 秒）；製作流程看 `docs/02_端到端流程.md`，技術限制看 `docs/03_規則與踩坑.md`。
> - 首幀：原頻道用 OpenAI Image 2.5（`tools/img25.py`）；全本地做法見 `docs/07_本地角色與首幀.md`。

## 開工前必讀（不可跳過）

1. 你專案的角色設定檔（外觀、聲音、表情）。角色外型一律**引用設定檔**，不在劇本裡自己重寫。
2. 抓馬與節奏：`references/drama-hooks.md`（四種差、20 個模式、0–3 秒節奏）；**入戲條件**：`references/audience-entry.md`（熟悉的人物／場景／故事＋各自一個意外、「這就是我」、衝突要快答案要慢、前 3 秒靜音測試）。
3. **系列作**：該系列的 `系列設定.md`（＝系列聖經）與 `製作規則_累積.md`。每集照做，交付後把新規則補進累積檔。
4. 專案 `CLAUDE.md` 的通用規則與 `docs/03_規則與踩坑.md`。

## 固定規格

| 項目 | 值 |
|:---|:---|
| 畫面比例 | **預設 9:16 直式（YouTube Shorts）**；使用者指定才做 16:9 橫式。兩種都要重新生成，**不裁切** |
| 長度 | 1–3 分鐘（Shorts 上限 3 分鐘；H3 每鏡多出的空白要修剪） |
| 鏡頭 | 首幀 → 本機 H3；**每鏡 ≤12 秒**（超過容易自己切鏡、漂移）；沒台詞的過場鏡約 3 秒內 |
| 幀率 | 24 fps |
| 配音 | 畫面內角色台詞**預設 H3 自己念＋角色參考音**（spec `audio.voice_ref`；兩三人對話可同鏡：`audio.voice_refs` 各給參考音，最多 3 位）；參考音用真人錄（要吼的戲另錄兇的參考音）；**念錯再修**：換 seed 抽 2 次 → 請人錄那一句當固定音軌 → 沒人能錄、數字日期難字、精準聲畫同步才用 BreezyVoice（`tools/make_breezyvoice.cmd`）固定音軌。讀本試映只給文字、用字數估鏡長（`references/table-read.md`）。台詞避免單一個字（「考。」「接！」改成兩三個字） |
| 觀眾 | **一般人**（系列另有指定就照系列）：每個轉折、隱喻都要有一句台詞／旁白或一個畫面講白 |

## 判斷任務

- **完整一支／一集**：讀 `references/workflow.md`，九個階段＋生成前試映，**每階段過關卡**（列 3–5 條自檢、等使用者「通過／修改」）才往下。使用者說「一次做完」才跳過關卡，但自檢照做。
- **單點創作**（只要題材／結構／某一場／台詞／反轉）：讀 `references/workflow.md` 對應階段，**只交付指定成果**。
- **寫劇本或要格式**：讀 `references/format.md`。
- **排鏡表**（劇本已存在）：讀 `references/segmentation.md`。
- **生成前試映**：讀 `references/table-read.md`（`tools/make_storyboard.py`＋`tools/assemble_read.py`）。
- **審閱或修改**：讀 `references/checklists.md`。

## 共同規則

- 只詢問會實質改變結果的缺漏；其餘採合理假設並**清楚標示**。
- 保留使用者指定的長度、類型、觀眾、場景與交付形式。
- 寫**現在正在發生的可見行動**；動作要誇張一點、分鏡多一點（反應鏡、插入鏡、推近、汗珠特寫、全場同步轉頭）。轉成 H3 spec 時，`action` 照官方 `h3-prompt-writing` 技能寫 50–120 字的具體動作過程，動作鏡首幀畫「動作開始前」的姿勢（見 `references/segmentation.md`）。
- 每場至少改變資訊、關係、目標、風險或情緒之一；場與場之間是「因為…所以」，不是「然後」。
- 反轉必須能由前文線索回看成立，而且**被哪一句台詞或哪一個畫面翻掉要寫得出來**。
- **台詞和前後畫面要對得上**：台詞提到的動作先演出來、數量一致、「他／她」指誰看得出來、反應緊接動作。
- 節奏明快但不能快到看不懂：轉折後留一拍讓觀眾消化（反應鏡或一句講白）。
- 教室戲（原頻道常用）：老師不碰學生；黑板在前、學生面向黑板、窗在學生左手邊；上課期間背景要有同學。
- 使用者只要劇本時，**不輸出** H3 提示詞、seed、步數——那是製作階段（`tools/h3_shot.py`）的事。

## 輸出契約

**創作任務**：必要假設 → 主題錨點 → 指定創作成果 →（完整一支才附）鏡表與試映清單。

**審閱任務**：依影響程度排序的診斷、對應具體段落的證據、可執行的修改方向；只有能說明修正或使用者明確要求時才提供改寫。
