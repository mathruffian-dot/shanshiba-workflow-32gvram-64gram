# 山獅霸 AI 短劇：Blender 預演與交付包

## 這技能解什麼問題

AI 影片最常見的失敗是**空間隨機性**：座位跑掉、人物增生、背景冒出多餘物件、左右換位、道具位置漂移。
社群與本專案的共同結論是**先用 3D 鎖空間與運鏡，再交給影片模型生成**；參考影片能約束效果，但手動做 Blender 動畫太費時。

**但直接叫模型「去 Blender 做」大概率翻車——因為模型不知道表現的重點在哪。** 所以規則必須寫死在這個技能裡，不能靠每次臨場發揮。

**界線（不可含糊）**：本法**只解空間與運鏡**。它**不解決對嘴同步**。對嘴仍靠實際配音引導與最難鏡頭先測；**布置圖通過不等於對嘴或表演通過**。

## 開工前必讀（不可跳過）

1. 專案 `CLAUDE.md` 頂部最新紀錄與 `專案現況.md`
2. `資源索引/AI短片/答案索引_真人短劇交付工作流_20260922.md`（固定流程與踩坑對策）
3. 該片角色設定；生任何圖／影片前讀 `角色資產/山獅霸/角色設定.md`
4. 要用 Blender 時：`資源索引/AI短片/Blender_MCP_安裝_20260920.md`（連線方式與安全警告）

## 固定規格（本專案，不重複問）

| 項目 | 值 |
|:---|:---|
| 畫面 | **16:9 橫式**、**24fps** |
| 長度 | 1–2 分鐘成片；本機 H3 單鏡長度依台詞與合法幀數，**不套 Seedance 30 秒分段** |
| 影片模型預設 | 本機 **H3 Ref2VA**（＋實際配音引導） |
| 生圖 | 本機 Qwen-Image 2.1 |
| 高解析 | 原生 768p → 上下裁切 → RTX VSR 1080p |
| 運鏡參考 | Blender `Workbench` 平塗色算圖，不是最終風格 |

## 共同規則

- **需求先問齊再動工**：人物設定、場景、劇情走向、風格、禁則。本專案最大的時間浪費是「先批次生成才發現共通缺陷」。
- **生成之前先看畫面**：每鏡先算布置圖，再花 GPU。布置圖成本趨近於零。
- **一鏡一機位要說清楚**：不同鏡號若共用同一機位，要明講，不要讓鏡數看起來比實際畫面豐富。
- **運鏡與描述不可矛盾**：標了 locked 就不寫推進；想推進就必須真的做成 keyframe。這是已記錄的踩坑。
- **收件要鎖節點**：只取指定的 Save 節點輸出，不要遍歷所有輸出而誤收輸入素材。
- **不用局部貼片救表演**：禁止舊的嘴／眼 XY 平移貼片修法；表演問題回生成端或重做必要短鏡。
- **技術通過 ≠ 使用者認可**：兩者分開記錄；音素級對嘴未量測就照實寫。

## 輸出契約

**預演任務**：需求確認 → 鏡表（含機位）→ 場景與布置圖 →（必要時）運鏡 → 檢查結果。

**交付包任務**：素材清單 ＋ 提示詞 ＋ 逐鏡參數 ＋ 已知限制。打包到該片的交付資料夾，並保留可重跑的設定。

**絕不**：自行改動既有交付版本、覆寫別人正在用的檔案、或把未驗收的結果寫成已通過。
