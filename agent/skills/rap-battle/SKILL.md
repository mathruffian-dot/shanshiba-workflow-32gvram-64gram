# 饒舌對決（rap battle）

一場對決＝**兩位真實人物各唱一整首歌互嗆**，DJ 主持開場、換場、收尾，最後留言投票。橫式 3–4 分鐘，觀眾是一般人。
製作工具是 `pipeline/template_battle/`（`battle.json`＋`make_battle.py`），本技能負責「想清楚、寫好、生好歌、交給範本、審片」。

## 開工必讀

1. `references/design.md`：選題、人物、DJ、結局、配色（**每場配色跟前幾場不同**）。
2. `references/lyrics.md`：歌詞規則（押法混用、唱段像流行副歌、殺句、兩邊一起改、讀音）。
3. `references/songs.md`：生歌（**先問使用者有沒有 Suno**）、檢查、兩首怎麼接。
4. `references/video-spec.md`：影片規格、鏡表寫法、H3 規則、特效。
5. `references/review-checklist.md`：交片前逐秒自審。
6. 範本說明 `pipeline/template_battle/README.md`；H3、首幀的通用規則 `docs/03_規則與踩坑.md`、`docs/07_本地角色與首幀.md`。

## 階段與關卡

每階段交付後列 3–5 條自檢，等使用者說「通過」或給修改才往下（使用者說「直接做到好」才跳過關卡，但自檢照做）：

| 階段 | 交付 | 關卡 |
|:--|:--|:--|
| 1 研究 | 兩位人物的史實、爭議點、可對到現代觀眾的梗（附出處） | 史實可查、梗一般人懂 |
| 2 對決設計 | 片名、誰先出場、DJ 是誰與為什麼、結局（反轉或定論）、投票打什麼字、配色 | `design.md` 檢查表 |
| 3 歌詞 | 兩首完整歌詞＋**兩邊對照表**（A 丟的每個點 B 怎麼接） | `lyrics.md` 檢查表 |
| 4 生歌 | 每人各抽 2–4 版，挑好的給使用者試聽（附逐句聽寫低分句） | 使用者聽過說可以 |
| 5 角色定妝 | 兩位饒舌手＋DJ 參考照（三人臉型、鬍型、頭飾都不同） | 使用者選定 |
| 6 鏡表 | `battle.json` 的 shots（50–60 鏡）、字卡文字 | 每句歌詞都有對應畫面 |
| 7 成片 | `make_battle.py` 一路做到 v1 | 自審（下方）→ 使用者審片 |

## 生歌：先問

**開始生歌前一定先問使用者：「你有 Suno 帳號嗎？」**
- 有 → 用 Suno（網頁 Custom 模式貼 `out/songtext/suno_*`，或 Kie API `kie_suno.py`）。編曲最豐富、rap 最有攻擊性、會有刷碟聲。
- 沒有 → 問要不要改用本機 **YuE2 14 版範本**（`templates/song_yue2_v14/`），說清楚：攻擊性和韻律感比 Suno 弱、權重 CC BY-NC 不能商用。不要自己默默換。
- YuE2 也不滿意 → Plan C **ACE-Step 1.5**（`tools/ace_song.py`，拍速最穩、MIT 可商用，但人聲有金屬聲）。
- 本機跑不動 YuE2 的人：Colab 完整安裝已預裝 YuE2，`python cloud/colab_h3.py film <對決資料夾> yue` 在雲端生歌；有 Suno 還是最省事。

## 自審（交片前一定做）

`make_battle.py review` 產生每秒一格的接觸表與自己切鏡偵測，照 `references/review-checklist.md` 一張張看，問題列成清單（時間、鏡號、問題、處理）→ 修 → 再出一版再看一次。**送給使用者的是 v1 和問題清單，最後一定要人看完整成片。**

## 共同規則

- **兩人各一首完整的歌**：同一首歌裡分兩個人，聲音會是同一個人；Suno 的 extend 接第二人也會變回第一人。
- **一嗆一笑**：一人唱的時候，另一人閉嘴、不屑微笑（反應鏡、雙人同框都一樣）。
- **觀眾是一般人**：典故太難就換現場梗；每個轉折要有一句歌詞、一張字卡或一個畫面講白；傳說要寫「傳說」，數字要有出處。
- **配色、封面每場都換**：開工先列最近 2–3 場用過的配色，選一套貼題材、又不一樣的（場景燈光、字幕、特效、字卡、封面一起換）。
- DJ 口白預設用 **Ming-3.0-TTS**（MIT，可商用；`make_battle.py dj`）。參考音預設由 Breeze TTS 2 依文字設計（不能商用）→ 要營利就自己錄一段 10–20 秒放 `out/voice/ref_K.wav`。
- 授權：Suno 看你的方案（免費方案通常不能商用）；YuE2 權重、Qwen-Image 2.1、Breeze TTS 2 都不能商用；MiniMax H3 授權排除美、歐盟、英、南韓（Colab 機房在美國／歐盟：照常使用，工具會顯示警語，風險自負）。公開時標示 AI 生成。
